Задание по ознакомительной практике, Вариант №22

В процессе функционирования  АСУ  ВД  в  файле  фиксируются данные о самолетах, совершивших посадку. Каждая запись имеет структуру типа:

       932        Б-3489        12.6            51
       номер      бортовой      вес         количество
       рейса      номер         груза       контейнеров

  1) подготовить программу, сортирующую записи с использованием индексной сортировки методом «пузырька» в порядке убывания номеров рейсов; определить суммарное количество контейнеров; результаты печатать в виде таблицы;
  2) обеспечить входной контроль номера рейса, бортового номера, веса груза и количества контейнеров, выполнить отладку и тестирование.

Чтение данных их файла производить с использованием функций ввода/вывода языка С++.
Алгоритм должен быть параметризован; обмен данными с подпрограммой должен осуществляться только через параметры; исходные  данные  хранятся в отдельном файле.
  
Комментарий о работе:  
    
Программа имеет 2 способа обработки данных:  
1)Игнорирует некорректные строки;
2)Не игнорирует некорректные строки и завершается при нахождении ошибок.
В первом случае программа проходит по всем строкам в файле, определяет их корректность и оставляет для сортировки только правильные варианты. Неправильные строки отбрасываются, так как, во-первых, ошибка может напрямую влиять на сортировку, во-вторых, данные могут выглядеть странно или содержать логические ошибки, например номер рейса из букв или рейсы с одинаковыми номерами.  
Во втором случае программа завершается на первой ошибке. Способ подходит для полностью корректных данных  
  
Файлы с тестами:  
1)Файл data01.txt содержит как корректные, так и некорректные строки;  
2)Файл data02.txt содержит только корректные строки;  
3)Файл data03.txt содержит корректные и пустые строки или строки из пробелов;  
4)Файл data04.txt содержит только пустые строки или строки из пробелов;  
5)Файл data05.txt пустой;  
  
Чтообы код корректно работал и правильно обрабатывал русские буквы и вещественные числа(в русской локали разделителем является ',', а не '.'), замените кодировку в файлах flights.cpp, data.txt и data2.txt с UTF-8 на windows1251(Cyrillic) в вашей среде разработки!!!
